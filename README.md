# Opinionated Agent Engineering Sharing

Static multi-page Astro site for an opinionated technical sharing session on building agents.

## Commands

```bash
pnpm install
pnpm dev
pnpm build
pnpm preview
```

Open the page at the URL printed by `pnpm dev`, usually `http://localhost:4321`.

## Editing

Pages live in `src/pages/`:

- `index.astro`
- `what-is-agent.astro`
- `session-state-memory.astro`
- `orchestration.astro`
- `engineering-practice.astro`
- `function-tools.astro`
- `skills.astro`
- `code-execution.astro`
- `eval-observability.astro`
- `harness-engineering.astro`
- `harness-examples.astro`

The shared side-nav layout lives in `src/layouts/SiteLayout.astro`.

Visual styling lives in `src/styles/page.css`.
